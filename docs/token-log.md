### Calculation

If GitHub displays **AIC used**:

```text
AIC consumed = End AIC used − Start AIC used
```

If GitHub displays **remaining AIC**:

```text
AIC consumed = Start remaining AIC − End remaining AIC
```

```text
Team AIC consumed = Sum of each participant's AIC consumed
```
